\subsection{Robustness to parameter initialization}
\label{subsec:experimental_initialization_statistics}
Initialization sensitivity was assessed using 30 stable random starting vectors for each benchmark and parametrization. Candidates were drawn by adding componentwise uniform perturbations in $[-0.5,0.5]$ to $[0,0,1,0,0,0]^\top$, retaining only vectors whose signal- and noise-model poles have modulus below $0.95$. Within each implementation, the same starting vectors were supplied to all methods while keeping a single $10000$-sample data record fixed, with $\sigma_\nu=0.1$ and unchanged optimizer settings and iteration budget. Finite-output counts and the dispersion of the returned parameter estimates were examined separately.

In Example~1/FSM, Newton and both LHAM variants return tightly clustered estimates from all 30 starts; BI-HMC point estimates are also closely clustered. By comparison, GHAM-1-dH and GHAM-2-H exhibit occasional extreme errors, reaching approximately $124\%$ and $251\%$, while GHAM-2-dH and GHAM-2-I fail for some starts. In PL, the diagonal-Hessian GHAM variants yield almost identical parameter vectors whenever they complete, whereas WS-GGI and GHAM-2-I retain appreciable dependence on initialization. RLS and WS-GNI return only 13 and 15 finite estimates, respectively, in each PL benchmark. LHAM-3-TIK is more concentrated than LHAM-1-TIK in Example~1 but retains an occasional large error in CSTR. All available CSTR/FSM methods return finite estimates from every start, with greater dispersion for the second-order GHAM variants than for Newton, GI, GHAM-1-dH, and the LHAM rules.
